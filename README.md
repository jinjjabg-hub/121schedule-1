# 121 스케줄 · 설치 안내

파일 1개만 올리면 챕터 전체가 씁니다. 한 번만 세팅하면 끝입니다.

## 1. Firebase 준비 (5분, 무료)

1. https://console.firebase.google.com 접속 → **프로젝트 만들기**
   (이미 쓰는 프로젝트가 있으면 그대로 써도 됩니다)
2. 왼쪽 메뉴 **빌드 → Firestore Database** → **데이터베이스 만들기**
   → 위치는 `asia-northeast3 (서울)` → **프로덕션 모드**로 시작
3. **규칙** 탭 → `firestore.rules` 파일 내용을 통째로 붙여넣기 → **게시**
4. 왼쪽 위 **⚙️ 프로젝트 설정** → 아래로 스크롤 → **내 앱 → 웹(</>)** 추가
   → 나오는 `firebaseConfig` 값을 복사

## 2. index.html에 설정 붙이기

`index.html` 파일을 열면 위쪽에 이 부분이 있습니다.

```js
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  ...
};
```

여기를 1번에서 복사한 값으로 통째로 교체하고 저장하세요. **이 부분만 바꾸면 됩니다.**

## 3. GitHub Pages에 올리기

1. 새 레포 만들기 (예: `one21`) → Public
2. `index.html` 업로드 → Commit
3. Settings → Pages → Branch: `main` / `(root)` → Save
4. 1~2분 뒤 주소가 나옵니다 → `https://아이디.github.io/one21/`

이 주소 하나를 챕터 단톡방에 뿌리면 끝입니다.

## 사용법 (챕터원에게 안내할 문구)

```
[121 시간 잡기 링크]
아래 주소에서 본인이 가능한 시간을 고르시면
나만의 예약 링크가 만들어집니다.
그 링크를 원투원 하실 대표님께 보내주세요.

https://아이디.github.io/one21/

※ 만든 뒤 나오는 '관리용 링크'는 꼭 카톡 나에게 보내기로
   저장해 두세요. 예약 현황은 그 주소에서만 보입니다.
```

## 알아둘 점

- 로그인이 없습니다. **관리용 링크(`&k=...`)를 아는 사람만** 예약 현황을 봅니다. 잃어버리면 다시 만들어야 합니다.
- 같은 시간을 두 사람이 동시에 누르면 **먼저 누른 사람만** 예약되고, 뒷사람에게는 "다른 분이 먼저 예약했다"고 안내됩니다.
- 예약 알림(문자·카톡)은 자동으로 가지 않습니다. 예약한 사람이 확인 문구를 복사해 보내는 방식입니다.
- 무료 한도(Firestore 하루 읽기 5만 건)로 챕터 규모는 넉넉합니다.
